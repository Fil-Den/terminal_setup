# AGENTS.md

Instructions for AI coding agents working in this repository.

## Git

- **Never push to GitHub without explicit confirmation from the user.** This applies to `git push` in any form (new branches, existing branches, tags, force pushes) and to anything that publishes to the remote, such as opening or updating pull requests via `gh`.
- Local commits are fine, but ask before pushing — and ask again each time; approval for one push does not cover later ones.
